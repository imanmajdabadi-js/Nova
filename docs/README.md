# Docs

This directory contains the product and architecture contract for NOVA. It is intentionally text-only — no application code or dependencies live here.

## Contents

- `product.md` — Product domain, roles, and user journeys.
- `domain.md` — Core data entities and their relationships.
- `routes.md` — Planned route architecture (public, auth, customer, host, admin).
- `rendering.md` — Rendering strategy per page type (Static, ISR, SSR, CSR).
- `state-management.md` — Responsibility of each state layer (TanStack Query, Redux Toolkit, local state, URL state).
- `components.md` — Component architecture (UI, domain, feature components) and page composition.
- `ui-libraries.md` — Styling/UI library responsibilities (Tailwind, MUI, Ant Design).
- `typescript.md` — TypeScript rules and configuration.
- `naming.md` — Naming conventions.
- `git.md` — Git/commit conventions.
- `definition-of-done.md` — Definition of Done.

## Status

These documents describe intent. Actual implementation may deviate; update docs as decisions are finalized.
